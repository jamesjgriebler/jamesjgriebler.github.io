===================================================

This file is gitignored: it stays on this computer and is NOT published
to the website. Edit it freely.

PUBLISHING FROM A TERMINAL
--------------------------

From inside the folder, the whole thing is one line:

    git add -A && git commit -m "Fill in the CV degrees" && git push

From anywhere else, without needing to cd first:

    git -C "C:/Users/james/jamesjgriebler.github.io" add -A && git -C "C:/Users/james/jamesjgriebler.github.io" commit -m "Fill in the CV degrees" && git -C "C:/Users/james/jamesjgriebler.github.io" push

Change the message in quotes each time to say what you did.


PUBLISHING FROM VS CODE
-----------------------

1. Edit and save            Ctrl+S
2. Source Control panel     Ctrl+Shift+G
3. Click a file to see exactly what changed before publishing it
4. Type a message in the box at the top, click Commit, say yes to staging
5. Click Sync Changes, or the up-arrow in the blue status bar

If VS Code asks you to sign in to GitHub, sign in as jamesjgriebler.
VS Code keeps its own GitHub login, separate from git's, and this machine
also knows the old JamesGriebler8 account.


AFTER PUSHING
-------------

The site rebuilds in about 30 to 60 seconds. If the page looks unchanged
after that, hard-refresh with Ctrl+F5 - the browser caches the stylesheet
and will happily show you the old one.

Check what you are about to publish first:

    git status

Everything committed to this repository is served publicly, so a stray
file at the root is readable at https://jamesjgriebler.github.io/<filename>


USEFUL CHECKS
-------------

What is being ignored right now:

    git status --ignored

Why a particular file is ignored, with the matching rule:

    git check-ignore -v path/to/file

What you changed but have not yet committed:

    git diff

Recent history:

    git log --oneline


THINGS TO KNOW ABOUT THIS REPO
------------------------------

- Placeholder text is wrapped in <span class="placeholder">, which renders
  with a yellow highlight so unfinished text is obvious on the page.
  List everything outstanding:

    grep -rn "placeholder" --include=*.html .

  When the site is finished, delete the .placeholder rule from
  assets/styles/site.css; anything still highlighted is something missed.

- The nav bar is duplicated in all six HTML files. There is no template
  engine. To add or rename a page, use Find and Replace Across Files in
  VS Code (Ctrl+Shift+H) so no copy is missed.

- Do NOT commit large files. GitHub rejects any file over 100 MB, and a
  published Pages site must stay under 1 GB. Anything committed stays in
  .git history forever, even if deleted afterwards. The scanned bulletin
  archive is excluded in .gitignore for this reason.

- DOI links must be absolute: https://doi.org/... and not doi.org/...,
  which the browser treats as a path on this site and 404s.
